Original LICENSE, NOTICE, COPYRIGHT and PATENTS texts are copied; builds fail if a dependency has no license text. Snitch remains MIT; do not describe the complete app image as MIT-only. Worker images retain Python/Debian base notices and installed wheel metadata and copy full distribution license files into `/usr/share/licenses/snitch/python`. `worker/voice-runtime.lock` pins the complete Python 3.12 closure including the `voice` extra; `build.lock` pins poetry-core 2.2.1 (verified PyPI release, Python >=3.9). Installation uses no build isolation or dependency re-resolution and runs `pip check`. certifi is MPL-2.0, httpx/httpcore/idna BSD-3-Clause, typing_extensions PSF-2.0; other runtime packages MIT. Build backend/pip/base distribution notices remain included too.

The project no longer redistributes the PostgreSQL/pgvector and Ollama images. `compose.yaml` references the upstream images directly, pinned by digest as in `upstream-images.json`, and they are pulled from their own registry (Docker Hub) under their own licenses and notices. PostgreSQL/pgvector use the PostgreSQL license; Ollama MIT also bundles other components. Inspect upstream image notices for the complete distribution. Do not present entire containers as exclusively MIT.

Pinned source digests, npm lock, go.sum and explicit Python locks make dependency resolution reproducible. Generated clients are checked byte for byte. Image bytes/build timestamps and external registry availability are not promised reproducible; CI and publication target amd64 (NAS N100 / GPU PC); local validation also built arm64. No image is published by a local build; images are pushed only by the CI jobs on `main` and `v*` tags (`snitch` and `snitch-worker`, both built from this repository).

The worker image (`deploy/docker/worker.Dockerfile`, example in `deploy/worker/`) is the only worker image (the former CPU-only image and `runtime.lock` were removed).
