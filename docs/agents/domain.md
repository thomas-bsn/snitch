# Domain docs

Contexte métier unique.

Avant d'explorer un sujet, lire GLOSSARY.md et les ADR de docs/adr/ qui concernent ce sujet.
Employer les termes du glossaire et signaler explicitement toute contradiction avec un ADR.

Si un document manque, poursuivre sans imposer sa création.
Les termes et décisions sont documentés lorsqu'ils sont résolus.
Le glossaire reste un glossaire métier, sans détails d'implémentation.
Les décisions techniques non triviales sont consignées dans un ADR avec contexte, décision, alternatives écartées et conséquences.

ROADMAP.md décrit les phases ; docs/specs/ contient leurs specs.
